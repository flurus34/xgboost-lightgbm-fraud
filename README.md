# Масштабируемое машинное обучение: Репликация и оптимизация XGBoost и LightGBM

Репозиторий содержит материалы технологической практики магистратуры ИГУ по направлению «Прикладная информатика» (Большие данные и интеллектуальные системы).

##  Описание проекта
Проект посвящен исследованию, программной репликации и модификации современных масштабируемых алгоритмов градиентного бустинга над решающими деревьями (GBDT) на основе статей из рейтинга CORE A/A*:
* **XGBoost:** Chen & Guestrin, KDD 2016
* **LightGBM:** Ke et al., NeurIPS 2017

В качестве экспериментальной базы взят крупный табличный набор данных с выраженным дисбалансом классов (Credit Card Fraud Detection). Целью модификации являлось повышение качества классификации миноритарного класса без потери вычислительной эффективности.

##  Структура репозитория
* `train.py` — основной скрипт для предобработки данных, обучения базовых моделей и оптимизированной версии.
* `requirements.txt` — конфигурационный файл среды с фиксацией версий зависимостей.
* `feature_importance.png` — визуализация весов информативности признаков для обеих моделей.
